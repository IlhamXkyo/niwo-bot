Semua foto di sini dipakai sebagai header tombol.
Tiap kategori punya foto SENDIRI (beda-beda).

Nama file = nama kategori. Contoh: ai.png, game.png, tools.png
Format: .png .jpg .jpeg .webp

menu.png     -> menu utama
allmenu.png  -> menu semua fitur
button.png   -> foto default untuk tombol fitur lain (conn.sendButton)

Mau ganti foto? Timpa saja filenya dengan nama yang sama,
tidak perlu edit kode. Restart bot setelah ganti.
Cek daftar: ketik .listasset
